# Chrome ウェブストア 掲載情報（ルーマニア語）

ダッシュボードの掲載情報タブでルーマニア語を追加し、該当する欄に貼り付けます。
カテゴリ・サポート用リンク・プライバシータブは言語ごとの設定がないため、
[store-listing.ja.md](store-listing.ja.md) / [store-listing.en.md](store-listing.en.md) のとおりです。

> ルーマニア語の文面は機械的に作ったものです。可能であればネイティブの方の確認を受けてください。

## 拡張機能名・概要

この 2 つはダッシュボードで直接編集できません。パッケージ内の `_locales/ro/messages.json` の
`name` と `description` がそのまま使われます。

| 欄 | 現在の値 |
| --- | --- |
| 拡張機能名（最大 75 文字） | `GitHub Issue Read Marker` |
| 概要（最大 132 文字） | `Marchează paragrafele din issue-urile și pull request-urile GitHub cu ✓ sau × și adaugă notițe private în timp ce citești.` |

## 詳細な説明

```
În discuțiile lungi din issue-urile și pull request-urile GitHub pierzi ușor firul: ce ai citit deja și
unde ai vrut să obiectezi? GitHub Issue Read Marker îți permite să marchezi și să adnotezi, paragraf cu
paragraf, descrierea și fiecare comentariu din issue-uri și pull request-uri (fila Conversation).

■ Marchează orice paragraf cu ✓ / × și adaugă o notiță
Treci cu mouse-ul peste un paragraf și în stânga apare bara [✓] [×] [Notiță].
・✓ — ceva ce ai citit sau verificat
・× — ceva la care vrei să obiectezi
・Notiță — un comentariu despre acel loc, vizibil doar în browserul tău
Apasă din nou același buton pentru a elimina marcajul.
Sunt acceptate paragrafe, elemente de listă, titluri, blocuri de cod, rânduri de tabel și titlurile
secțiunilor pliabile.

■ Compune un răspuns din notițe și ×
Alege „Compune un răspuns din notițe și ×” din meniul de clic dreapta sau din fereastra pictogramei
extensiei, iar fiecare fragment marcat este adunat ca citat Markdown, cu notița ta dedesubt.
Bifează ce vrei să incluzi: fragmente cu notițe, fragmente marcate cu ×, fragmente marcate cu ✓.
Listele își păstrează „-”, blocurile de cod își păstrează delimitatorii, iar rândurile de tabel sunt
citate separate prin „|”, astfel încât forma originală a textului se păstrează.
Răspunsul poate fi inserat direct în caseta de comentariu de la finalul paginii sau copiat în clipboard.

■ Vezi cât ai citit
O insignă în colțul din stânga jos arată câte paragrafe ai marcat din totalul paragrafelor de pe pagină.
Apasă pe ea pentru a sări la următorul paragraf nemarcat.

■ Citește doar cu tastatura
Alt+Shift+J selectează paragraful următor, Alt+Shift+C comută ✓, Alt+Shift+X comută ×, Alt+Shift+N
scrie o notiță (pe Mac folosește Option în loc de Alt). Le poți schimba la chrome://extensions/shortcuts.

■ Marcajele tale sunt salvate
Marcajele și notițele sunt salvate pentru fiecare pagină și reapar data viitoare când o deschizi.
„Pagini salvate” afișează toate issue-urile și pull request-urile marcate, începând cu cele mai recente.
Exportă datele într-un fișier JSON și importă-le din nou pentru a le muta pe alt calculator.
Când nu mai ai nevoie de ele, șterge o singură pagină sau toate paginile neactualizate de peste 90 de zile.

■ Limbi
Interfața este disponibilă în română, engleză și japoneză și urmează limba browserului.

■ Confidențialitate
Această extensie nu comunică niciodată cu vreun server extern.
Marcajele și notițele rămân doar în browserul tău (chrome.storage.local) și nimeni — nici măcar
dezvoltatorul — nu le poate citi.
Întregul cod sursă este publicat pe GitHub:
https://github.com/activeguild/github-issue-marker

■ Notă
Aceasta este o extensie neoficială și nu este afiliată, susținută sau sponsorizată de GitHub, Inc.
```
