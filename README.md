# GitHub Issue Read Marker

<img src="icons/icon128.png" width="96" align="right" alt="">

長い GitHub Issue や Pull Request を読むときに、本文やコメントの段落ごとに **✓ / ×** のマークとメモを付けておける Chrome 拡張機能です。
付けた印はブラウザー内に保存され、次に同じページを開いたときにそのまま復元されます。

対象は Issue のページと、Pull Request の **Conversation（会話）タブ**です（Files changed などほかのタブは対象外）。

[English](README.en.md) | 日本語

## できること

### 段落ごとにマークとメモを付ける

Issue の本文やコメントの段落にマウスを乗せると、左側に **[✓] [×] [メモ]** のツールバーが出ます。

- **✓** … 読んだ・確認した箇所の目印
- **×** … 指摘したい・引っかかった箇所の目印
- **メモ** … その箇所へのコメント（自分のブラウザー内だけに表示されます）

同じボタンをもう一度押すと解除されます。

対象になるのは `.markdown-body` 内の段落・リスト項目・見出し・コードブロック・表の行・`<summary>` です。

### メモと × から返信コメントを下書きする

右クリックメニューまたはツールバーアイコンから **「メモと×から返信コメントを作成」** を選ぶと、
印を付けた箇所を Markdown の引用（`>`）として集め、その下に自分のメモを添えた返信文を組み立てます。

```markdown
> ここが引用された元の文です

ここに書いたメモが入ります
```

- 対象は「メモがある箇所 / ×の箇所 / ✓の箇所」からチェックボックスで選べます
- 文書順に並び、リストは `-`、コードブロックはフェンス付き、表の行は `|` 区切りで引用されます
- **［コメント欄に挿入］** でページ下部の新規コメント欄へ直接差し込めます（Undo も効きます）
- **［コピー］** でクリップボードへコピーもできます

### ページ単位でまとめて消す

右クリックメニューまたはツールバーアイコンから **「このページのマークとメモをすべて消去」** を選びます。
件数を確認するダイアログが出てから消去されます。

### どこまで読んだかを表示する

ページに 1 つでもマークを付けると、画面左下に「✓ か × が付いた段落の数 / ページ全体の段落数」が出ます（例: `45 / 120 箇所を読了（38%）`）。
コメントが読み込まれるにつれて全体の数は増えます。バッジを押すと、✓ も × も付いていない次の段落へ移動します。

### キーボードで操作する

| 操作 | 既定のキー |
| --- | --- |
| 次の段落を選ぶ | `Alt+Shift+J`（Mac は `⌥⇧J`） |
| 選んだ段落の ✓ を切り替え | `Alt+Shift+C` |
| 選んだ段落の × を切り替え | `Alt+Shift+X` |
| 選んだ段落にメモを書く | `Alt+Shift+N` |
| 前の段落を選ぶ | 未設定 |
| 次の未読の段落へ移動 | 未設定 |
| メモと×から返信コメントを作成 | 未設定 |

選んでいる段落は青い枠で示されます。何も選んでいない状態でマークのキーを押すと、まず画面内の先頭の段落を選ぶだけです。
入力欄で文字を打っている間は反応しません。キーの変更や割り当ては `chrome://extensions/shortcuts` で行えます（ツールバーアイコンのポップアップに今のキーと、設定画面へのリンクがあります）。

### 保存したページの一覧と、書き出し・読み込み

ツールバーアイコンのポップアップの **「保存したページの一覧」**（拡張機能のオプションページと同じ）で、マークやメモを付けた Issue と Pull Request を新しい順に一覧できます。件数と読了率も表示されます。ここでは次のことができます。

- ページを開く・削除する
- 90 日以上更新のないページをまとめて削除する
- すべてのデータを JSON ファイルに **書き出し**、別の PC などで **読み込む**。
  すでにあるページとは段落ごとに統合し、同じ段落が両方にある場合は更新日時が新しいページの方を残します
  （新しい側にメモが無ければ、古い側のメモは消さずに残します）

## インストール

### Chrome ウェブストアから

> 審査が通りしだい、ここにリンクを掲載します。

### ソースから読み込む（開発者向け）

1. このリポジトリを clone するか、ZIP をダウンロードして展開します
2. Chrome で `chrome://extensions` を開きます
3. 右上の **デベロッパー モード** をオンにします
4. **［パッケージ化されていない拡張機能を読み込む］** をクリックし、このフォルダーを選びます

## プライバシー

**外部への通信は一切ありません。** マークとメモは `chrome.storage.local` によってお使いのブラウザー内にのみ保存されます。
詳しくは [PRIVACY.md](PRIVACY.md) をご覧ください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `content.js` | GitHub の Issue / PR ページ上で動く本体。ツールバー・メモ・返信作成パネル・読了率バッジ・キーボード操作 |
| `content.css` | 上記 UI のスタイル。GitHub の Primer CSS 変数に追従します |
| `background.js` | 右クリックメニューの登録と、メニュー・キーボードショートカットから content.js へのメッセージ送信 |
| `popup.html` / `popup.js` / `popup.css` | ツールバーアイコンのポップアップ |
| `overview.html` / `overview.js` / `overview.css` | 保存したページの一覧と書き出し・読み込み（オプションページを兼ねる） |
| `_locales/` | 名前・概要と画面の文言（英語・日本語・ルーマニア語）。ブラウザーの表示言語で切り替わり、該当が無ければ英語 |
| `icons/` | 拡張機能アイコン（`icon.svg` が原本） |

ビルド手順はありません。素の JavaScript / CSS をそのまま読み込みます。

### 配布用 ZIP を作る

```sh
./scripts/package.sh
```

`dist/github-issue-read-marker-<version>.zip` が作られます。拡張機能の動作に必要なファイルだけが含まれます。

## 動作環境

Manifest V3 に対応したブラウザー（Chrome 88 以降、Edge、Brave など Chromium 系）
